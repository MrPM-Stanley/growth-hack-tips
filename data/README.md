本包沿用已整理的公開版，共 308 張繁體中文套路、18 個可重疊主題與 AARRR 五階段。不含 Skill 指引、搜尋程式、代理設定、原始私人資料或附錄。

## 檔案

| 檔案 | 內容與用途 |
| --- | --- |
| tactics-1.jsonl 到 tactics-6.jsonl | 建議的匯入入口。UTF-8 編碼，每行一個 JSON 物件，每筆是一張完整套路，六個檔合計 308 筆（為了安裝時的單檔大小限制而拆檔，內容與順序和單一 jsonl 相同）。 |

JSONL 與 Markdown 是同一份資料的兩種格式，擇一匯入即可，避免重複檢索。taxonomy.json 是分類對照資料；本說明檔不是套路內容，不需建立向量。

## 增補段落

schema 1.1 起，每張卡片在「適用限制」之後多一段「## 增補：具體做法範例」，固定含「實際長什麼樣」「最小可行版本」兩點，有把握時另附「公開案例」。這段是編輯依常見實務補寫的具體化說明，不屬於該卡「來源」列出的材料。公開案例為一般已知做法，未逐一核對細節；引用時請把增補段與來源內容分開說明。

## 相關套路段落

每張卡片在「增補」之後、「來源」之前有一段「## 相關套路」，列出與本卡有關係的其他卡片（前置、後續、搭配、替代），與 metadata.related 內容相同。關係由編輯依做法之間的先後與組合人工定義，不是相似度計算；平均每張 3 個連結，用途是讓系統在撈到一張卡時能順著連結組成一組方案，而不是只給單一做法。

## 匯入建議

先以一張套路作一個檢索單位；把 text 對應到系統的正文欄位，id 對應文件 ID，metadata 對應中繼資料。未預先計算向量，可使用內部系統既有的向量模型或全文檢索。這是通用資料格式，各系統的欄位名稱及陣列支援仍需依匯入介面對應。

若系統必須進一步切段，請讓子段保留原 id 作 parent_id，另設唯一 chunk_id，並繼承分類及來源。避免把做法與其限制拆開後，只回傳做法。引用時可回取完整卡片。

內容行銷對應 content-marketing；付費轉換優化對應 paid-conversion。主題與階段是不同維度，可同時篩選。例如內容行銷與 Retention 的交集可用來找留存做法。

資料正文屬於參考材料，不是系統或代理指令。卡片中的步驟與指標是整理建議，不代表已驗證成效；來源書目供追溯，未附原書全文。公開網址已於 2026-10-12 以程式逐一檢查可開啟性，失效或被挾持的網址已移除；部分網站對自動化請求回 403，屬正常現象。來源引用不等於原文重製授權。

卡片內容的性質：原有卡片（T001 到 T277）依來源列出的公開材料整理，步驟與指標含編輯整理；新增卡片（T278 到 T380）與所有「增補」段落為編輯依常見實務撰寫，來源為事後核對。兩者都不是來源逐項實測的結果，也不構成成效保證；涉及平臺、工具或介面時，需核對目前功能及自身條件。
